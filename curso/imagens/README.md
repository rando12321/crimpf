# Ilustrações da edição ampliada

Nove pranchas geradas por inteligência artificial para apoio didático. Não são fotografias de pacientes nem registros de atendimento. As legendas e as explicações clínicas estão em `../apostila.md` e no PDF.

| Arquivo | Tema |
| --- | --- |
| acesso-seguro.png | Rampa, corrimãos e supervisão |
| marcha-aquatica.png | Posição inicial e passada à frente |
| marcha-lateral.png | Deslocamento lateral sem cruzamento |
| transferencia-peso.png | Transferência lateral de peso com os pés apoiados |
| miniagachamento.png | Flexão pequena com apoio |
| quadril.png | Abdução de quadril com apoio |
| ombro.png | Movimento anterior de ombro em imersão |
| panturrilha.png | Elevação bilateral dos calcanhares |
| equilibrio.png | Alcance previsível com apoio e supervisão |

As posições são ilustrativas, sem escala de profundidade, ângulos prescritos, equivalência de carga ou validação clínica da execução. A seta entre duas posições indica sequência de leitura; não representa força. Os critérios de segurança e a individualização precisam acompanhar a leitura de cada prancha. Antes da oferta do curso, a revisão técnico-científica deve incluir imagens e legendas.

Os arquivos PNG são os originais. A opção `--compact` do gerador otimiza a codificação das imagens dentro do PDF sem reduzir suas dimensões em pixels; os PNG permanecem intactos.
